# ksqlDB Examples

This folder contains ksqlDB examples demonstrating stream processing capabilities using the Orders data generated by the Datagen connector.

## Prerequisites

1. Confluent Platform deployed and running
2. Datagen connector producing to the `Orders` topic
3. ksqlDB accessible

Verify with:
```bash
./scripts/health-check.sh
```

## Files

| File | Description |
|------|-------------|
| `01-create-orders-stream.sql` | Create base stream from Orders topic |
| `02-create-orders-flat-stream.sql` | Flatten nested address structure |
| `03-create-aggregations.sql` | Aggregation tables (by state, by item, windowed) |
| `04-example-queries.sql` | Push and pull query examples |
| `deploy-ksqldb-objects.sh` | Script to deploy all objects |

## Quick Start

### Deploy All Objects

```bash
# Start port-forward to ksqlDB
kubectl port-forward svc/ksqldb -n confluent 8088:8088 &

# Deploy streams and tables
./ksqldb/deploy-ksqldb-objects.sh
```

### Interactive CLI

```bash
kubectl exec -it ksqldb-0 -n confluent -- ksql http://localhost:8088
```

## Example Queries

### Push Query (Streaming)

Watch orders in real-time:
```sql
SELECT * FROM orders_stream EMIT CHANGES;
```

Filter by state:
```sql
SELECT * FROM orders_stream
WHERE address->state = 'California'
EMIT CHANGES;
```

### Pull Query (Point-in-time)

Get current aggregations:
```sql
SELECT * FROM orders_by_state;
SELECT * FROM orders_by_state WHERE state = 'California';
```

### Windowed Query

Get orders per minute:
```sql
SELECT * FROM orders_per_minute
WHERE itemid = 'Item_1';
```

## Objects Created

### Streams

| Stream | Description | Source |
|--------|-------------|--------|
| `orders_stream` | Raw orders from Kafka | Orders topic |
| `orders_flat` | Flattened address fields | orders_stream |

### Tables

| Table | Description | Aggregation |
|-------|-------------|-------------|
| `orders_by_state` | Order stats per state | COUNT, SUM |
| `orders_by_item` | Order stats per item | COUNT, SUM |
| `orders_per_minute` | 1-minute tumbling window | COUNT, SUM |
| `orders_rolling_5min` | 5-min hopping window | COUNT, AVG |

## Cleanup

To drop all objects:

```sql
DROP TABLE IF EXISTS orders_rolling_5min DELETE TOPIC;
DROP TABLE IF EXISTS orders_per_minute DELETE TOPIC;
DROP TABLE IF EXISTS orders_by_item DELETE TOPIC;
DROP TABLE IF EXISTS orders_by_state DELETE TOPIC;
DROP STREAM IF EXISTS orders_flat DELETE TOPIC;
DROP STREAM IF EXISTS orders_stream;
```

## REST API Examples

### Execute a query via REST

```bash
curl -X POST http://localhost:8088/ksql \
  -H "Content-Type: application/vnd.ksql.v1+json" \
  -d '{"ksql": "SHOW STREAMS;"}'
```

### Run a pull query

```bash
curl -X POST http://localhost:8088/query \
  -H "Content-Type: application/vnd.ksql.v1+json" \
  -d '{"ksql": "SELECT * FROM orders_by_state WHERE state = '\''California'\'';"}'
```
